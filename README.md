# Kiss

**A completely free, open-source app for listening to local music on your phone.**

*If you download music, do it beautifully.*

> The only safe place to download Kiss is this official repository.

## Features

- Plays the MP3 files stored on your phone, and can add all audio from your phone in one tap (optional permission)
- Covers (photo or GIF), titles and artists that you choose yourself
- Playlists with their own covers
- Two designs: Liquid Glass and Retro 2000s
- English and Russian, chosen on first launch
- 10-band equalizer with presets, plus slowed and speed-up modes
- Sleep timer, crossfade and cover pulsing to the beat
- System media notification and lock-screen controls
- No internet permission: nothing leaves your phone

## Install

1. Open the **Releases** page of this repository (right side of the main page).
2. Download `Kiss.apk` from the latest release. No login and no zip needed.
3. Open the file and install it. Android will ask you to allow installs from unknown sources.

Direct link to the latest version: `https://github.com/kurisu-love/Kiss/releases/latest/download/Kiss.apk`
